# T1547.001 - Registry Run Key Persistence (Sentinel / KQL)

Windows analog of the Linux autostart-persistence rules (cron T1053.003 / systemd
T1543.002 / kernel-module T1547.006). On Windows the common autostart is a Run key.

| Field | Value |
|---|---|
| ATT&CK | T1547.001 - Boot or Logon Autostart: Registry Run Keys |
| Platform | Defender XDR (DeviceRegistryEvents) / Sentinel (Sysmon EventID 13) |
| Sample | EVTX-ATTACK-SAMPLES: `Persistence/evasion_persis_hidden_run_keyvalue_sysmon_13.evtx` |

## KQL - Defender XDR advanced hunting
```kql
DeviceRegistryEvents
| where ActionType == "RegistryValueSet"
| where RegistryKey has @"\CurrentVersion\Run"
| where RegistryValueData has_any ("\\Users\\Public\\", "\\Windows\\Tasks\\", "\\Temp\\",
                                   "\\AppData\\Local\\Temp\\", ".vbs", ".ps1", "powershell")
| project Timestamp, DeviceName, InitiatingProcessFileName, RegistryKey,
          RegistryValueName, RegistryValueData
```

## KQL - Sentinel (Sysmon EventID 13)
```kql
Event
| where Source == "Microsoft-Windows-Sysmon" and EventID == 13
| extend TargetObject = tostring(EventData.TargetObject),
         Details      = tostring(EventData.Details),
         Image        = tostring(EventData.Image)
| where TargetObject has @"\CurrentVersion\Run"
| where Details has_any ("\\Public\\", "\\Tasks\\", "\\Temp\\", ".vbs", ".ps1")
| project TimeGenerated, Computer, Image, TargetObject, Details
```

## Validation
- Against the sample: Sysmon EventID 13, `TargetObject` =
  `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run\`, `Details` =
  `"c:\windows\tasks\taskhost.exe"`, `Image` = `C:\Users\Public\tools\evasion\a.exe`.
- The rule keys on the run-key write pointing at a suspicious path, so it fires on this
  hidden-run-value persistence.

## Notes
- Legitimate software also writes Run keys at install time - the path/value filter is the
  tuning lever (same idea as excluding package managers on the Linux cron rule).
- A production version scopes to non-standard installers by `InitiatingProcessFileName`.
